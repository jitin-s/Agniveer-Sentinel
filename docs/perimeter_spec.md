# Tactical Perimeter & Geofencing Specification

## Sector Zoning
- **Sector Alpha**: Primary forward operating boundary (FOB).
- **Sector Bravo**: Secondary staging perimeter.
- **Sector Charlie**: Tactical command base and sensor hub.

## Sensor Thresholds
- High frequency coordinate refresh: 10 Hz
- GPS drift deadband: 1.8 meters
- Ray-casting bounding box pre-filter for sub-millisecond evaluation.
